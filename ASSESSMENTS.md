# Учебный маршрут Bora — обновление 17.11.2026

30 занятий, по 19 шагов: объяснение на русском → словарь → озвученные примеры → аудирование → сборка фразы → пропуск → буква → две проверки смысла → короткое чтение → фотография и подпись → контролируемое письмо → мини-текст с самопроверкой → пять итоговых вопросов → результат и следующее занятие. На экране одно действие. Готовые MP3 работают без вызова TTS при прохождении. Голосовой помощник и его переходы скрыты; старые ссылки на разговор возвращают к занятиям. Генерация новой озвучки сейчас ограничивается ответом 429 сервиса; новые тексты чтения и описания доступны текстом, имеющиеся фразы и аудирование имеют готовые файлы.

Новые ответы: `courseProgress['pt/<id>'].guided`, версия 1. Старые done, answers, correct и note сохраняются. Повторная попытка сохраняет два компактных предыдущих результата с черновиками. Завершение не зависит от AI, микрофона и трёх реплик: пять итоговых ответов, включая «Пока не знаю», открывают итог и следующую тему. Неправильные тренировочные ответы можно исправлять. Неправильные итоговые ответы не исправляются до окончания пяти вопросов. Свободный текст и подпись картинки сохраняются без ложного автоматического зачёта грамматики; для мини-текста нужна самостоятельная проверка трёх пунктов. Итог 4/5 — внутренняя отметка закрепления, не CEFR.

Диагностика v3: 6–24 вопроса, три ответа без вариантов на ступень; для повышения нужны 5/6 и все продуктивные ответы. Рекомендация начинается с ранее проверенной опоры, а не с первой непроверенной сложной темы. При «С нуля» рекомендуется Oi даже после сильной проверки. Можно пропустить диагностику и начать с нуля. v2 не используется для высокой рекомендации; предлагается простой маршрут и повторная диагностика. Выбранное начало `learningPath` имеет приоритет над старыми сложными черновиками. Есть простые объяснения для всех тем и возврат к основам без удаления результатов.

Общий пробник: четыре авторские письменные задачи по структуре Celpe-Bras (видео, аудио, два текста), три часа либо учебный режим без таймера. Первые 30 минут в режиме с таймером только задача 1. Медиа до двух запусков; пауза на текущем экране не расходует дополнительный. Готовое видео — иллюстративное слайд-шоу, озвучка синтетическая pt-BR. Таймер по времени устройства, не прокторинг. Просроченная попытка заканчивается при открытии соответствующей части.

Устная подготовка после удаления помощника — только самостоятельные темы по картинкам и письменные заметки, с 20-минутным таймером либо без него. Это не замена интервью с экзаменаторами и не проверка произношения. Разбор сохранённых письменных ответов доступен по запросу через `/api/exam-feedback`: сессия, RLS, общий лимит, чтение завершённой попытки из БД по проверенному user ID; клиентские подменные ответы не используются. Никаких официальных баллов, уровня или обещаний гражданства. Разбор AI может ошибаться.

Прогресс хранится в существующем Supabase JSON под RLS. В браузере только сессия входа. Ссылки на источники и лицензии вынесены из занятий на `materials.html`; фотографии — `photo-credits.html`, видео — `exam-credits.html`. Все новые тексты и ситуации авторские, адаптированные примеры атрибутированы. Методические ориентиры: UW–Madison Português para principiantes, COERLL Língua da Gente, коммуникативный подход Caminhos, официальный формат INEP. Это основа бытового общения и постепенная практика интегрированных навыков, не обещание полного покрытия CEFR или гарантированной сдачи Celpe-Bras.
