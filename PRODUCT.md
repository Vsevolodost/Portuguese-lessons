# Bora Português

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Личный пилот для двух русскоязычных учеников, в том числе начинающих с полного нуля. Занимаются на телефоне и компьютере. Интерфейс должен быть понятен без технического опыта.

## Product Purpose

Изучение бразильского португальского для бытового общения и последующей подготовки к Celpe-Bras. Объяснения на русском, короткие понятные примеры, постепенное усложнение. Учебные проверки не являются официальной сертификацией.

## Operating Context

Выбор начала с нуля или предварительная проверка → последовательные занятия → закрепление и повторение слов → сохранённый прогресс. Программа и результаты доступны отдельно. Ученик может пропустить задание и вернуться позже.

## Capabilities and Constraints

- Только pt-BR; английский удалён по запросу пользователя.
- Сохранить существующие аккаунты, авторизацию, результаты, словарь и идентификаторы занятий.
- Существующий стек: статический HTML/CSS, модульные браузерные JS-скрипты, серверные Node.js API на Vercel, Supabase Auth/PostgreSQL/Storage. Render не используется.
- Поддерживать светлую и тёмную темы, клавиатуру и мобильную навигацию.
- Реальные записи носителей и явно обозначенный синтез pt-BR. Голосовой помощник скрыт по запросу пользователя.
- Программа содержит 36 занятий; восемь вводных пересобраны для полного нуля. Каждая тема дополнена тренировкой из шести коротких заданий, памяткой и повторением ошибок.
- Сервис личный бесплатный; монетизация пока не реализована.

## Brand Commitments

Название Bora; бразильская направленность, фотографии Бразилии, простая дружелюбная русская речь. Пройденные занятия имеют заметное зелёное выделение.

23 ноября 2026 пользователь выбрал новый характер интерфейса: «Путешествие по Бразилии: карта, города и отметки пройденного». Требуется выразительный, необычный визуальный мир при сохранении простого учебного пути.

## Evidence on Hand

Учебные данные в dist/courses-data.js и dist/beginner-course.js; реальные пользовательские результаты в Supabase. Изображения и сведения об их происхождении в dist/lesson-photos.js, dist/assets/lessons, dist/assets. Данные для скриншотов локального предпросмотра технические, не публичная статистика продукта.

## Product Principles

1. Каждое задание опирается на уже объяснённый материал.
2. В каждый момент очевидно, какое занятие продолжить.
3. Визуальные состояния отражают реальные результаты, а не вымышленные достижения.
4. Карта и игровые элементы помогают ориентироваться; они не блокируют занятия.
5. Объяснения и упражнения остаются короткими по форме и достаточными по содержанию.

## Accessibility & Inclusion

Читаемый текст, понятные подписи, заметные состояния и фокус, управление без перетаскивания, работа при reduced motion. Карта имеет доступную альтернативу списком; цвет не единственный признак завершения.
