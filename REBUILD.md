# Перестройка Bora: рабочая ветка

Ветка: codex/bora-course-rebuild. 24.11.2026 пользователь разрешил завершить работу и выполнить деплой без дополнительного подтверждения. Вход, профиль, карта и экзамен сохраняются на проверенных маршрутах; новый интерфейс публикуется под /learn.

## Архитектура

Модульный монолит: существующие Node.js API, Supabase Auth/Postgres/Storage и новый React + TypeScript интерфейс. Vite собирает клиент отдельно. Общие предметные модули: учебная программа, прохождение занятия, проверка ответа, интервальное повторение, словарь, разговор. Не переносим FastAPI/Redis только ради совпадения со стеком FreeLingo.

FreeLingo: исходная программа из 48 разделов A1–C2 сохранена в vendor/freelingo. Русские названия и цели адаптированы в frontend/src/data/curriculum.json. AGPL-3.0, лицензия и происхождение: COPYING, THIRD_PARTY_NOTICES.md. Лицензии фотографий и сторонних материалов сохраняются отдельно.

## Реализовано локально

- 52 занятия: 8 прежних начальных + 16 новых базовых + 28 прежних тематических. Это **не готовая полная программа A1–C2**.
- Новый учебный экран: слова, объяснение, примеры, диалог, выбор ответа, аудирование, сборка фразы, короткий письменный ответ. Подсказки привязаны к заданию.
- Ошибка и верный ответ различаются цветом, текстом и значком. Основное действие закреплено внизу мобильного экрана.
- Пропуск не даёт правильный ответ и не засчитывает урок; есть возврат к пропущенному.
- Отдельное повторение с сохранением исходной статистики; освоение требует отложенной проверки.
- Словарь по одной карточке, очередь по сложности; результаты сохраняются через общий прогресс.
- Домашняя страница выбирает следующий непройденный урок. Программа открывает описание конкретного занятия.
- React сохраняет совместимые старые поля прогресса. Серверная проверка пользователя и RLS остаются существующими. Последовательная очередь сохранения, revision, защита от перезаписи другого устройства, предупреждение при уходе с несохранёнными ответами.
- Разговор по теме: текст, диктовка при поддержке браузера, озвучка; выход всегда доступен. Сервер извлекает только ошибки выбранного урока из профиля подтверждённого пользователя.
- Точные существующие аудиофайлы используются прежде динамической озвучки. AI-черновики не входят в готовые уроки.

## Проверено

Сборка TypeScript/Vite. Исходный набор 134 тестов и 5 новых проверок прошли после изменений. Ручной путь на ширине 390: первый урок, ошибка, повторная попытка, аудирование, все финальные ответы, завершение, переход в разговор и выход на главную. Главная показала 1 завершённое занятие и предложила следующее. Только тестовая память локального сервера; настоящий аккаунт и база в этой проверке не участвовали.

Предпросмотр: npm run dev --prefix frontend + node scripts/preview-fixtures.cjs. Привязка только к 127.0.0.1, фиктивный ученик. API разговора/динамической озвучки в fixture-сервере намеренно не подключены; сохранённые аудиозаписи доступны. **Это не проверка настоящего AI/SMTP/микрофона на iPhone.**

## До выпуска обязательно

1. Закончить перенос авторизации, профиля/аватара, карты и экзамена: текущие разделы production должны сохраниться. Не подменять отсутствующие маршруты страницей «О курсе».
2. Дополнить новые начальные занятия слушанием и упражнениями разных форматов; редакторская проверка каждого незнакомого слова до его проверки. Расширить A1–A2 реальными проверенными уроками, а не одним планом.
3. Полные занятия A1–C2 писать и проверять по разделам. Структурно корректный JSON от LLM не считается методически проверенным материалом.
4. Заменить слайд-шоу, обозначенное видео, настоящим лицензированным движущимся материалом; согласовать запись, задание, расшифровку и атрибуцию. Эта проблема пока не исправлена.
5. Проверить реальную интеграцию AI/голоса, поздние ответы после ухода, разрешение микрофона, сетевые ошибки и повторные запросы. Провести проверку аккаунтов на двух устройствах без изменения настоящего прогресса.
6. Устранить оставшиеся пробелы доступности и сделать финальный дизайн-аудит. Проверить соответствие обещаний о лицензиях/исходниках фактической публикации.
7. Настроить выпуск и откат Vercel, показать пользователю рабочую версию и изменения, получить явное подтверждение, затем пуш/деплой.

## Выпуск 24.11.2026

Основной интерфейс опубликован коммитом 549497a. Проверены production-маршруты, защита прогресса без входа, вход технического тестового аккаунта, чтение его прогресса и ответ GigaChat по новому уроку. Учебные ответы не изменялись, созданная тестовая сессия закрыта. Динамический Edge TTS из Vercel дал 502 при работающем локальном сервисе. Подготовлены сохранённые MP3 для всех произносимых слов и фраз 24 базовых уроков; для произвольных реплик добавлен запасной голос устройства только pt-BR. Наличие и качество такого голоса зависят от устройства. Требуется отдельный стабильный речевой провайдер для гарантированной озвучки произвольных диалогов. Видео со слайдами пока не заменено настоящим съёмочным материалом: загрузка Wikimedia не завершилась.
