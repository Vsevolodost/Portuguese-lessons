# Bora — учебный пилот

Сайт для двух учеников: диагностика, первый урок, локальный прогресс и помощник GigaChat с RAG на бразильском португальском и английском. Объяснения на русском.

## Запуск

Node.js 24. Скопируйте `.env.example` в `.env`, заполните ключ и приватный код пилота. Запуск: `node --env-file=.env server.cjs`. Для системного хранилища сертификатов при необходимости используйте `--use-system-ca`. Не отключайте проверку TLS.

`npm test` проверяет маршруты, поиск, авторизацию API, лимиты и обмен с моделью через заглушку. Реальный запрос оплачивается по условиям вашего аккаунта GigaChat.

## Помощник

`/api/chat` доступен по коду пилота (заголовок X-Pilot-Code). Ключ GigaChat хранится только на сервере. История и результаты — в localStorage браузера; код — в sessionStorage. Общий код не заменяет отдельные аккаунты. Вопрос, короткая история и учебный профиль передаются GigaChat.

RAG использует 890 фрагментов и поиск BM25; русские вопросы переводятся моделью в поисковые термины. Ответ показывает источники. Проверка фактов и качество поиска пока требуют редакторской оценки; это не полноценный курс и не официальная оценка готовности к Celpe-Bras.

Лимиты: 6 запросов в минуту на IP, 2 одновременных, 200 в сутки на процесс; при перезапуске сбрасываются. Оригиналы PDF/MP3 хранятся отдельно, в Git размещён текстовый индекс с лицензиями. Аудиоплеер пока не подключён.

## Render

Source: Vsevolodost/Portuguese-lessons, branch main, Root Directory пустой. Build: `node --check server.cjs && node check.cjs`. Start: `npm start`. Health: `/health`.

Environment: GIGACHAT_AUTH_KEY, GIGACHAT_SCOPE=GIGACHAT_API_PERS, GIGACHAT_MODEL=GigaChat-2, BORA_PILOT_CODE. Значения секретов не коммитить.

Следующие этапы: отдельные аккаунты и БД, проверка учебных материалов преподавателем, воспроизведение записей носителей, интервальные повторения и аудирование. Фото предоставлены пользователем; права на их публичное использование отдельно не проверены.
