# Восстановление доступа: ещё не подключено

В личном пилоте email-подтверждение выключено по решению владельца. Отправка писем и восстановление забытого пароля не проверены и не объявлены работающими.

Unisender Go технически совместим с Custom SMTP Supabase, но требует подтверждения домена отправителя через DNS. Бесплатный старт отправляет только на адреса подтверждённых доменов. Для произвольных адресов нужен другой тариф: на момент проверки 13 ноября 2026 указан пробный период два месяца, затем от 800 рублей в месяц. У владельца пока нет своего домена; аккаунт и платный тариф не создавались. Обычный бесплатный тариф маркетингового Unisender нельзя автоматически считать тарифом SMTP Go.

Когда будет выбран подходящий почтовый сервис:

1. Подтвердить разрешённого отправителя и получить SMTP-настройки; ключи вводить только в Supabase Custom SMTP.
2. Проверить production Site URL и разрешённые redirect URLs для https://portuguese-lessons.vercel.app/.
3. Настроить русские письма подтверждения и восстановления. Не менять email-подтверждение до проверки доставки, чтобы не заблокировать новых учеников.
4. По явному запросу владельца отправить тестовые письма на выбранные адреса. Проверить доставку, переход по ссылке, смену пароля, повторный вход и прежний прогресс. Не отправлять тесты произвольным ученикам.
5. После успешной проверки включить требуемое подтверждение email в Supabase и emailConfirmationRequired в supabase-public.json, опубликовать сайт и проверить реальную регистрацию.

Источники: https://godocs.unisender.ru/get-started ; https://godocs.unisender.ru/smtp-api ; https://go.unisender.ru/ .
