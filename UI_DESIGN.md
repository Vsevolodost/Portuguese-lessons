# Bora: интерфейс для обучения

Обновление посвящено бразильскому португальскому. Макет сделан для существующего приложения: новые экраны используют прежние уроки, Supabase Auth, прогресс и API. Тяжёлый клиентский фреймворк не добавлен. Открытые решения использованы точечно: Lucide для SVG-иконок; подходы WAI к навигационным областям, понятным названиям кнопок и видимому фокусу. Компонентный подход shadcn/ui изучен как ориентир, его код и React-зависимости не импортированы.

## Структура
- `dist/refresh.css`: визуальные токены, оформление и адаптивная раскладка; базовые формы и поведение остаются в `dist/style.css`.
- `dist/ui.js`: главная, каталог, чистый фильтр уроков, режим фокуса и выделение текущего раздела. Поиск проверяет названия, ситуации, объяснения и примеры на русском/португальском; ударения и регистр не влияют. Фильтры сохраняются в URL, не в учебном прогрессе.
- Компьютер: боковая навигация. Телефон до 700 px: нижняя панель с безопасным отступом. Режим без отвлечений скрывает навигацию только в уроке и всегда имеет кнопку выхода; при переходе в другой раздел выключается.
- Реальные показатели прогресса, без вымышленных дней серии, учеников и достижений. Рекомендации берутся из текущего маршрута.

## Изображения и иконки
Пять изображений предоставлены владельцем в чате; используются как визуальные материалы проекта. Права на исходные изображения отдельно не подтверждались. Файлы преобразованы в WebP, суммарно около 515 КБ, увеличения исходного разрешения нет. В карточках ниже первого экрана изображения загружаются лениво.
Иконки: lucide-static, ISC с MIT-частью для исходных Feather-иконок; полный текст лицензии сохранён в dist/assets/licenses/lucide.txt. В браузер попадает только спрайт из 31 выбранной иконки. Пересборка: npm run build:icons. Sharp нужен только как инструмент подготовки изображений.

Источники:
- https://github.com/lucide-icons/lucide
- https://github.com/shadcn-ui/ui
- https://www.w3.org/WAI/ARIA/apg/patterns/landmarks/examples/navigation.html

## Проверка
`npm test` включает ui.test.cjs: сочетание фильтров, поиск без учёта ударений, экранирование текста, сохранность заданий всех 30 уроков, отсутствие изменения прогресса при фильтрации и выход из режима фокуса. Визуальная проверка в браузере отдельно проверяет компьютер и узкие экраны. Реальные микрофон и клавиатура телефона требуют проверки на устройстве; эмуляция размеров их не заменяет.
